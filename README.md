# ポートフォリオ公開サイト

HTML,CSS,JavaScriptを用意手制作するポートフォリオサイトです。

**URL:**[
https://abe-sh1.github.io/](http://abe-sh1.github.io/)

GitHub Pagesを利用して公開してます。

## 使用技術・開発環境
- フロントエンド...HTML5、CSS3、JavaScript
- 開発環境...EclipseIDE
- バージョン管理...Git/GitHub
- 開発フロー...GitHub Flow
- ホスティング...GitHub Pages

## 開発・バージョン管理
開発にはGitHub Flowを採用しています。

バージョン番号は[Semantic Versioning](https//semver.org/lang/ja/)を参考に管理し、リリース時にはGitタグとGitHub Releasesを利用します。

## 変更履歴・リリース情報
各バージョンの変更履歴は、Keep a Changelogを参考に'CHANGELOG.md'で管理しています。

- **[CHANGELOG.md](CHANGELOG.md)** ーバージョンごとの変更内容
- **[GitHub Releases](https://github.com/abe-sh1/abe-sh1.github.io/releases)**
- リリースノート・Gitタグ・ソースコード
